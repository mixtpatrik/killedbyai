Migrating off a retired AI model: frequently asked questions

What should I migrate to when an AI model is deprecated?

Start with the replacement the vendor names, shown next to each entry on this page, and test it against your own prompts before the deadline. A newer model can answer differently even when the vendor presents it as the direct successor.

What happens if I miss the shutdown date?

It depends on the vendor. Some return an error for the retired model ID. Others reroute requests to a newer model without failing, which changes your output and can change what you are billed. The shutdown calendar notes it when a vendor has announced rerouting.

Where do the replacements on this page come from?

From the source linked on each row: the vendor's own deprecation page, changelog or announcement where one exists, otherwise named reporting. Where the vendor names no replacement, the row says so.

Are the alternatives on this page paid placements?

The replacement on each row is the vendor's own recommendation and is never paid for. A sponsored alternative is shown on a separate line and labelled Sponsored. None are running at the moment.
