Upcoming AI Shutdowns

Coming soon to the graveyard: the deprecation schedule for 21 AI products with confirmed death dates. Already announced, just counting down.

Last updated: September 9, 2026 · 📅 Subscribe to the shutdown calendar (.ics)

MAI-Code-1-Flash (GitHub Copilot)

Today

Announced August 21, gone from Copilot September 10 — twenty days' notice for a model that was itself the named replacement for Raptor mini. The only Copilot retirement on the calendar after September 8.

Killed by: GitHub / Microsoft Shutdown: 2026-09-10 Replacement: MAI-Code-1.1-Flash Source

Amazon Nova Gen-1 (Premier, Sonic, Canvas, Reel)

4d left

Amazon's first-generation Nova line is being cleared off Bedrock: Premier and Sonic on September 14, Canvas and Reel on September 30. Nova launched at re:Invent in December 2024 as Amazon's answer to frontier models; the second generation replaces it inside two years.

Killed by: Amazon Shutdown: 2026-09-14 Replacement: Nova 2 Sonic / Nova 2 Lite; Luma Ray v2 for video Source

MAI-Transcribe-1 (Microsoft Foundry)

5d left

Version 2026-01-23, retired September 15, 2026 — less than eight months old. Microsoft's first-party speech model line is now on the same accelerated churn as its image models.

Killed by: Microsoft Shutdown: 2026-09-15 Replacement: MAI-Transcribe-1.5 Source

Sora API

14d left

While the Sora app died in April, the API endpoint survives until September. Then it's gone completely.

OpenAI davinci-002, babbage-002 & gpt-3.5-turbo-instruct

18d left

The end of the GPT-3 base-model lineage. These three shipped in August 2023, inherited the job when the original ada/babbage/curie/davinci died in January 2024, and are the last models served over the legacy /v1/completions endpoint. Their own fine-tuned versions outlive them by 25 days.

Killed by: OpenAI Shutdown: 2026-09-28 Replacement: gpt-5.6-terra Source

Mistral Leanstral 1.5

20d left

Mistral announced this Lean 4 formal-proof model's death in the same sentence that announced its birth. The changelog reads: 'We released Leanstral 1.5... This model will be retired on September 30, 2026.' A 92-day advertised lifespan, dead on arrival by design.

Killed by: Mistral Shutdown: 2026-09-30 Replacement: None named Source

Amazon Mechanical Turk

20d left

The 21-year-old marketplace Jeff Bezos once called "artificial artificial intelligence" — the humans who labelled a generation of training data — closes on September 30, 2026. New customers were cut off July 30. Amazon cites "an internal assessment of its programs and services"; everyone else notes that the models MTurk workers trained now do MTurk's job.

Killed by: Amazon Shutdown: 2026-09-30 Replacement: None — Scale AI, Mercor and Prolific absorbed the market Source

Gemini Omni Flash Preview

20d left

Google's text-and-image-to-video model shipped June 30, 2026 and was deprecated on August 27, the day gemini-omni-1.1-flash went GA. Shutdown September 30 — a 92-day life, with the successor announced and the death date set in the same changelog entry.

Killed by: Google Shutdown: 2026-09-30 Replacement: gemini-omni-1.1-flash Source

Google Gemini 2.5 Flash Image ("Nano Banana")

22d left

The image model that went viral as 'Nano Banana' and briefly made Gemini the #1 free iPhone app shuts down exactly one year after release, to the day. Google's officially recommended replacement, gemini-3.1-flash-image-preview, was itself shut down in June 2026. The migration target is dead; the model isn't yet.

Killed by: Google Shutdown: 2026-10-02 Replacement: gemini-3.1-flash-image-preview (already retired) Source

Azure OpenAI GPT-4.1, 4.1 mini & 4.1 nano

34d left

GPT-4.1 launched April 2025 as OpenAI's 'best model for coding' with a 1M-token context window. Azure retires it, plus mini and nano, after 18 months. Fine-tuned deployments on the same bases get a one-year stay of execution.

Killed by: Microsoft Azure Shutdown: 2026-10-14 Replacement: gpt-5 / gpt-5-mini / gpt-5-nano Source

Sora 2 on Azure OpenAI / Foundry

35d left

Sora outlives its maker's own shutdown by three weeks: Microsoft pushed the Azure retirement from September 15 to October 15, with no replacement. OpenAI's own Sora API dies September 24. The last place to generate a Sora video will be a Microsoft data centre.

Gemini 2.5 Pro / Flash / Flash Lite (Vertex AI)

36d left

Google's entire Gemini 2.5 family retires on Vertex AI no earlier than October 16, 2026. Note this is Vertex-only — the Gemini Developer API still lists no shutdown date for the same three models.

Killed by: Google Shutdown: 2026-10-16 Replacement: Gemini 3.x series Source

Azure OpenAI o-series (o1, o3, o4-mini, o3-pro)

41d left

Azure deletes an entire generation of reasoning models in under 90 days: o3-mini October 1, o4-mini October 16, o1/o1-pro/o3 October 21, codex-mini November 15, o3-pro December 17. Four have no named replacement — Microsoft declares one only 90 to 120 days out, because 'declaring a replacement too early risks directing customers to a model that is no longer the best available option.'

Killed by: Microsoft Azure Shutdown: 2026-10-21 Replacement: gpt-5.6-sol (partial); several unnamed Source

Vertex AI Open-Model MaaS (13 models)

41d left

Google Cloud drops managed serving for 13 open models on October 21 — DeepSeek V3.1, GLM-5 and 4.7, gpt-oss-20b, Kimi K2 Thinking, Llama 3.3 70B, MiniMax M2, two e5 embedding models and four Qwen3 variants. You can still run them; you just have to host them yourself.

Killed by: Google Cloud Shutdown: 2026-10-21 Replacement: Self-deploy the weights from Model Garden Source

OpenAI Fine-tuning (new orgs)

43d left

New organizations can no longer create fine-tuning jobs. The first wave executed on schedule July 23, 2026; the second takes every remaining fine-tuned model — ft-gpt-3.5-turbo, ft-gpt-4, ft-gpt-4.1-nano, ft-babbage-002 and ft-davinci-002 — on October 23.

Killed by: OpenAI Shutdown: 2026-10-23 Replacement: Prompt caching / system prompts Source

OpenAI GPT-4, GPT-4 Turbo, GPT-3.5 Turbo & the o-series

43d left

One date kills three eras. On October 23, OpenAI removes gpt-3.5-turbo (the engine that launched ChatGPT), gpt-4 and gpt-4-0613 (the model that defined 2023), and its entire first generation of reasoning models — o1, o1-pro, o3-mini, o4-mini — plus gpt-4o-2024-05-13 and gpt-image-1. Every fine-tune built on them dies the same day. Seventeen table rows, six months' notice.

Killed by: OpenAI Shutdown: 2026-10-23 Replacement: gpt-5.5 / gpt-5.4-mini / gpt-5.4-nano / gpt-image-2 Source

Vertex AI Extensions

Killed by: Google Cloud Shutdown: 2026-11-26 Replacement: Agent Platform Source

OpenAI Legacy GPT Image Models

82d left

Older GPT Image model snapshots were flagged for removal from the API on December 1, 2026, just months after they replaced DALL·E. The endpoint that buried DALL·E is already on its own deprecation clock.

Killed by: OpenAI Shutdown: 2026-12-01 Replacement: GPT Image 1.5 Source

OpenAI GPT-5 (original snapshots), o3 & o3-pro

92d left

The original GPT-5 launch snapshots — gpt-5-2025-08-07 and its mini, nano and pro siblings — plus o3 and o3-pro shut down December 11. GPT-5 launched in August 2025 as the 'PhD-level expert' model. Its launch snapshot gets 16 months before it starts returning errors.

Killed by: OpenAI Shutdown: 2026-12-11 Replacement: gpt-5.6-sol / gpt-5.6-terra / gpt-5.6-luna Source

OpenAI Realtime & Audio Model Family

132d left

OpenAI put its entire GA voice stack on death row: gpt-realtime, gpt-audio, gpt-realtime-mini, gpt-audio-mini and all four gpt-4o audio/realtime variants. gpt-realtime and gpt-audio went GA in August 2025 — the models that headlined 'production-ready voice agents' get roughly 17 months. OpenAI is skipping its own intermediate generation: the 1.5 series shipped in February 2026 and the named replacement is already 2.1.

Killed by: OpenAI Shutdown: 2027-01-20 Replacement: gpt-realtime-2.1 / gpt-realtime-2.1-mini / gpt-audio-1.5 Source

OpenAI Whisper-1 & GPT-4o Transcribe

169d left

On August 26 OpenAI deprecated whisper-1 — its original speech-to-text API from March 2023 — together with gpt-4o-transcribe, gpt-4o-mini-transcribe and gpt-4o-transcribe-diarize, the last of which shipped in October 2025. All four die February 26, 2027. The open-source Whisper weights are unaffected; the hosted endpoint that made them a product is not.

Killed by: OpenAI Shutdown: 2027-02-26 Replacement: gpt-transcribe / gpt-live-transcribe Source
