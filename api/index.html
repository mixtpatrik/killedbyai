{ API }

Free, open JSON API for discontinued AI products, AI-driven layoffs, and upcoming shutdowns. No auth, no rate limits, no API key.

Base URL

https://killedbyai.net/

All data is served as static JSON files. CORS is enabled by default. Responses are cached for 10 minutes (max-age=600, with an ETag).

Endpoints

Product graveyard

GET graveyard.json

All discontinued AI products, models, startups, and hardware.

Role labels

GET roles.json

An object mapping each roleTags key in layoffs.json to its display label, e.g. {"customer-support": "Customer support"}.

Shutdown calendar

GET deprecations.ics

An iCalendar (RFC 5545, text/calendar) feed with one all-day event per coming-soon.json shutdown date. Subscribe to webcal://killedbyai.net/deprecations.ics rather than importing it, and calendar apps refresh it daily.

RSS feed

GET feed.xml

RSS 2.0 feed of the 30 most recently added tombstones (pubDate = dateAdded, so older deaths that were added late still appear; guid = the tombstone URL).

Usage example

// Fetch all dead AI products
const res = await fetch('https://killedbyai.net/graveyard.json');
const graveyard = await res.json();

// Filter to only real kills (not model upgrades)
const realKills = graveyard.filter(p => p.deathType !== 'model-upgrade');

// Total funding burned
const burned = graveyard
  .filter(p => p.fundingM)
  .reduce((sum, p) => sum + p.fundingM, 0);
console.log(`$${(burned / 1000).toFixed(1)}B in funding burned`);
